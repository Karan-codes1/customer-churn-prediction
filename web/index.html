    How it works

    1. DataIBM's Telco Customer Churn dataset: 7,043 customers, 19 features covering demographics, services, contract and billing.
    2. PreprocessMissing total charges filled with the median. Numeric features standardised, categorical features one-hot encoded.
    3. TrainLogistic regression and a 200-tree random forest fitted on a stratified 80/20 split, then compared on held-out data.
    4. ServeThe fitted scaler, encoder and coefficients are exported from scikit-learn and evaluated in JavaScript, so there is no server to wait on.
